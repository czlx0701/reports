## 概述

本讲座探讨了自闭症谱系中睡眠障碍和身体活动模式的普遍性、生物学基础、测量方法和遗传学发现。Dr. B 团队利用体动记录仪（Actigraphy）收集了目前**规模最大的自闭症队列睡眠与活动数据**，并结合基因分析揭示睡眠问题的生物学机制。

---

## 一、为什么研究自闭症中的睡眠？

### 睡眠障碍的普遍性

来自 SPARK 联盟的照护者报告：

| 群体 | 有睡眠问题/诊断的比例 |
|------|----------------------|
| 自闭症人士 | 约**40%** |
| 非自闭症人士 | 约**10%** |
| 伴有智力障碍的自闭症 | 略高于40% |

**四人家族（Quartet Families）数据：** 自闭症先证者40%有睡眠问题，而其父母和未受影响的兄弟姐妹这一比例仅为**10%或更低**。

### 睡眠作为早期标志
- 睡眠问题往往是自闭症的**最早或首要征兆之一**
- 睡眠在大脑发育中起着至关重要的作用

### 双向关系
- **睡眠不足 → 加重自闭症症状**（社交技能下降、易怒、行为问题增加）
- 而规律睡眠的儿童学习更好、更少易怒、行为问题减少
- **反过来**：行为问题（如焦虑）也会**恶化**睡眠

### 共同的生物学基础
- 突触功能失调在自闭症**和**睡眠障碍中都有重要作用
- 许多自闭症风险基因参与突触发育和功能
- 睡眠期间突触结构会发生动态变化

## 二、睡眠调节的"双过程模型"

由 Borbély 在1990年代初提出，至今仍是指导性框架：

### 1. 昼夜节律过程（Circadian Process — Process C）
- 控制生理和行为的**每日节律**
- 即使在持续黑暗条件下仍保持约**24小时**的周期
- "Circadian" 源于拉丁语 "circa diem"（大约一天）
- 涉及从"昼夜节律觉醒促进"到"昼夜节律睡眠促进"的转换
- **Nobel Prize 曾授予**对该过程在果蝇中的研究

### 2. 稳态过程（Homeostatic Process — Process S）
- 调节睡眠压力的**逐渐上升**
- 清醒时间越长，睡眠压力越大

### 已知的调控基因
- 目前已知约**120个基因**，突变后可导致睡眠和昼夜节律紊乱
- 在模式生物（小鼠、果蝇、斑马鱼）中得到验证
- 部分已在人类中验证

## 三、睡眠的测量方法

### "金标准"：多导睡眠监测（Polysomnography, PSG）
- 在睡眠实验室进行，使用多种传感器
- 检测：脑电波、眼动、肌张力、心率、呼吸气流
- **主要局限：**
  - 通常仅测量**一个晚上**
  - 自闭症儿童和成年人在睡眠实验室环境中可能**极度不适**
  - 纵向数据对睡眠研究至关重要

### 替代方案：体动记录仪（Actigraphy）
- 腕戴式设备，可在**家中**连续佩戴数天至数周
- 记录活动水平、体位、温度和光照
- 适合收集**纵向、自然状态**下的数据

#### 设备选择

| 类型 | 举例 | 优势 | 局限 |
|------|------|------|------|
| 临床级 | Philips Respironics | 广泛用于睡眠诊所 | - |
| 研究级 | GeneActive, Activatch | **数据完全可控**，算法透明 | - |
| 消费级 | Fitbit, Oura | 便捷 | **算法为黑箱**，数据分辨率不如研究级设备 |

#### 体动记录仪的可视化

- **双标记录图（Double-Plotted Actogram）：** 每一条显示48小时，便于观察昼夜模式
- 可提取**超过200种**不同的睡眠和活动指标

#### 关键测量指标

| 指标 | 含义 |
|------|------|
| **M10** | 最活跃的连续10小时平均活动量 |
| **L5** | 最不活跃的连续5小时平均活动量 |
| **相对振幅（RA）** | 反映昼夜节律强度（夜间静止 vs. 白天活动的差异程度） |
| **入睡后觉醒（WASO）** | 睡眠期间的清醒时间 |
| **睡眠效率** | 实际睡眠时间/卧床时间 |
| **睡眠潜伏期** | 入睡所需时间 |

## 四、研究设计：SPARK中的最大规模体动记录研究

### 数据规模

- **阶段一：** 从宾大自闭症项目招募的**150名自闭症人士 + 230名家庭成员**
- **阶段二（SPARK）：** 已同意**700人**，完成问卷调查，其中**200人**获得高质量体动记录数据
- **总体：** 目前这是自闭症领域**规模最大的体动记录研究**

### 数据丰富度

每位参与者提供约**250项测量指标**，涵盖：
- **ASD特征：** SRS（社交反应量表）、BAPQ（广泛自闭症表型问卷）
- **执行功能：** BRIEF
- **睡眠评估：** 睡眠障碍、日间嗜睡、睡眠损害
- **感觉敏感性：** 格拉斯哥感觉敏感性问卷（GSQ）

## 五、初步发现

### 感觉敏感性分布
- SPARK自闭症参与者的GSQ评分分布明显右偏——许多人报告**显著的感觉敏感性**
- **听觉敏感性**特别突出（高分比例最高）

### 睡眠障碍分布
- 并非所有自闭症参与者都有睡眠问题——分布呈连续谱
- 有一批个体评分很低（无睡眠问题），另一批评分很高

### 活动模式的个体差异——引人注目的案例

**极端案例1：**
- 严重自闭症（SRS评分极高），但活动记录**极其规律、完美**
- 提示：严重的自闭症特征**不一定**伴随睡眠/活动紊乱

**极端案例2（高PROMIS评分）：**
- 白天活动量极低
- 夜间睡眠**高度碎片化**

**极端案例3：**
- 活动水平极高，睡眠极少

**极端案例4——自由运转（Free-Running）模式：**
- 每天的入睡和醒来时间**逐日推迟**
- 类似在"无时间线索"环境中的表现
- 这些个体似乎**对环境光/食物等授时因子不敏感**
- 类似日本神经学家 Dr. Sehata 在20年前报告的一个**长达一年的记录**——一个孩子的睡眠模式呈现周期性脱离环境线索

### 主要群体差异

| 指标 | 自闭症 vs. 未受影响亲属 |
|------|--------------------------|
| **入睡潜伏期** | **延迟**（入睡更困难） |
| **醒来时间** | **更晚** |
| **白天身体活动水平** | **显著更低** |
| **持续不活动（≥30分钟）** | **更多、时长更长** |
| **入睡后觉醒（WASO）** | 增加 |
| **睡眠效率** | 降低 |
| **所有指标的变异性** | **高得多** |

### 遗传力（Heritability）

- 睡眠和活动特质的遗传度为 **40%–60%**
- 说明**基因发挥重要作用**，但**环境因素也不容忽视**
- 对干预和治疗有重要启示：环境干预可以改变约40–60%的表型

## 六、基因发现与整合分析

### 基因组分析策略

1. **候选基因法：** 针对已知的120个睡眠/昼夜节律基因
2. **在ASD基因组序列中寻找罕见有害变异**
3. 验证这些变异是否影响睡眠/活动表型

### 挑战
- **遗传异质性极高：** 每个变异只在极少个体中发现
- 需要在**超大样本**中验证
- 个体间**日复一日的变异性极高**，需要纵向长时程记录

### 关键发现
- 在ASD先证者中发现了若干**已知睡眠/昼夜节律基因的罕见变异**
- 这些变异在模式生物中也已知会导致睡眠问题
- **性别差异明显：** 某些基因的变异在男女中表现不同
- **年龄差异显著：** 睡眠和活动模式随年龄变化

## 七、未来方向

### 马上启动的新项目
- Simons Foundation 资助的新试点项目（由 Dr. Elan Benstein 领导）
- 使用**Empatica Embrace Plus + Dreem 头戴设备**
- 可检测**EEG（脑电图）** 信号
- 招募**100个自闭症家庭**（自闭症儿童/青少年 + 未受影响兄弟姐妹）
- 记录**2–3周**

### 长期愿景
- 将可穿戴设备的睡眠和活动数据纳入**自闭症临床常规照护**
- 与计算机和数据科学家合作，整合海量传感器数据
- 理解生物与环境的交互作用

### 研究重点
- 与模式生物研究的平行整合 → 理解突触失调如何导致ASD相关睡眠问题
- 纵向研究（数月至数年）→ 捕捉动态变化
- 结合心率、心率变异性、血氧饱和度、EEG等多模态数据

## 结论与启示

1. 睡眠问题是自闭症谱系中最常见且影响深远的共病之一
2. 体动记录仪提供了一种**在家、纵向、高信息量**的评估手段
3. 自闭症相关的睡眠/活动异常既有**遗传基础**（40–60%），也有环境可塑性
4. 个体间差异极大——自闭症**不是单一的睡眠表型**
5. "自由运转"模式等极端表型提示部分自闭症人士可能**对环境中授时因子不敏感**
6. 未来，可穿戴设备数据有望成为自闭症**临床照护的可操作部分**
