> **主讲人**: Leanne Davis（Arc 全国刑事司法与残疾中心） & Samantha Crane（律师）
> **视频ID**: BKsKAP_2te0
> **系列**: SPARK 网络研讨会系列

## 概述

Leanne Davis 和 Samantha Crane 在本讲座中深入探讨了自闭症谱系人群及其他智力/发育障碍人士在刑事司法系统中面临的严峻挑战。她们提出了从"被动应对"转向"主动预防"的理念，通过系统改革（减少不必要的警察接触、改善紧急服务可及性、确保有效沟通）来构建预防文化。讲座重点介绍了 Arc 旗下的 "Pathways to Justice"（通向正义之路）培训项目及其在社区层面的实施。

## 二、从被动应对到主动预防

### 核心问题

长期以来，自闭症人士卷入刑事司法系统后的应对模式以 **被动反应** 为主——"出事了再想办法"。Davis 和 Crane 呼吁转变思维，创建 **预防文化**。

### 三个关键改革领域

1. **减少不必要的警察接触** — 在危机发生前介入
2. **改善紧急服务可及性** — 确保有适当的非警务替代方案
3. **确保有效沟通** — Davis 认为这是"最关键也是最根本的问题"

### 如何定义"危机"？

- 讲座强调：警察眼中的危机与自闭症人士或其照护者眼中的危机可能完全不同
- 培训中首先讨论的就是"危机对不同人意味着什么"
- 核心问题："是否有事情本可以在危机升级之前完成？"

## 三、Pathways to Justice（通向正义之路）培训

### 项目概述

Arc 的全国刑事司法与残疾中心通过一笔资助，开发了这个为期一天的培训项目。它不仅仅是培训，而是一个系统性的社区变革工具。

### 核心特色

| 要素 | 说明 |
|------|------|
| **跨学科团队** | 每场培训组建由执法人员、律师、受害者服务提供者、残障人士及其家庭成员共同组成的"残障应对团队" |
| **培训前准备** | 培训日之前与各专业人员预先沟通，确保协作顺畅 |
| **行动方案** | 培训结束时制定具体的社区行动计划 |
| **案例驱动** | 使用真实案例进行情景演练，确保实用性和代入感 |

### 刑司系统全景模型

培训使用一张贯穿刑事司法系统各环节的模型图：

```
社区 → 首次接触 → 调查 → 羁押 → 审判/认罪协议 → 转介 → 回归社区
```

在每一个环节，培训都引导参与者思考：

1. **识别**: 如何判断该人是否有自闭症或智力/发育障碍？
2. **沟通**: 如何确保该人能够有效沟通并理解自身权利？
3. **评估**: 如何评估当前状况并提供合理便利？
4. **支持**: 可以通过哪些社区资源提供持续支持？

## 四、数据与现状

### 惊人的数字

- 智力/发育障碍人士（含自闭症）占监狱人口的 **4–10%**（保守估计，实际可能更高）
- 涉及青少年司法的青少年中，约 **70%** 存在某种形式的障碍（包括智力/发育障碍和精神疾病）
- 自闭症和智力障碍人士比普通人群 **更易成为受害者**
- 非老年障碍成人中约 **27%** 生活在贫困线以下

### 当前执法培训的不足

- 大多数警员接受的残障培训集中在 **精神健康/精神疾病**（CIT——危机干预团队项目）
- 对自闭症和其他 **发育障碍** 的专门培训严重不足
- 警察、检察官、辩护律师往往将发育障碍与精神疾病 **混为一谈**

## 五、警员接触中的危险信号

培训课程教导执法人员识别可能提示发育障碍的信号：

| 信号 | 可能的误解 |
|------|-----------|
| 沟通/表达能力困难 | 被认为不配合或不诚实 |
| 易受他人影响、急于讨好 | 易被其他犯罪分子利用 |
| 不敢直视警察权威、顺从回答 | 可能导致虚假供述 |
| 不希望暴露残障身份 | 警官可能错过识别线索 |
| 对外界无反应 | 被误认为不尊重或反抗 |
| 被环境压倒、试图逃跑 | 被误解为有罪 |
| 避免目光接触 | 被误解为欺骗 |

Davis 分享了一个令人痛心的案例：五名嫌疑人被指控谋杀，最终只有那名患有智力障碍的人被定罪——后来通过 DNA 证据证明了其清白。

## 六、沟通技巧与合理便利

### 针对自闭症人士的沟通建议

- **不要触碰** — 触碰可能引起疼痛或过度反应
- **不要从背后靠近** — 可能引发惊恐反应
- **可能不回应语言指令** — 保持耐心，持续尝试
- **如有自刺激行为且无人身危险，耐心等待其自行消退**，然后冷静继续沟通

### 《美国残疾人法案》（ADA）的要求

- 必须为残障人士提供合理便利以确保平等接触司法系统
- 示例：
  - 花额外时间询问以判断是否存在残障
  - 确保有适合该人士的交流方式
  - 在有需要时呼叫残障服务组织或倡导者协助

---

## 七、系统性进展与倡导方向

### 积极信号

- 部分警察部门已开始制定专门的智力/发育障碍政策
- 与国际警察首长协会（IACP）合作，于 2017 年更新了针对智力/发育障碍的示范政策
- CIT 项目正在将自闭症纳入其主流培训内容

### 监狱与拘留所中的问题

- 需要更好的筛查系统
- 关注单独监禁对发育障碍人士的严重影响
- 确保提供适当的残障服务

### 倡导者的角色

Davis 呼吁倡导者们：

1. **抓住机会** — 无论本地、州还是全国层面，只要有关注残障/刑事司法的"开放之门"，就积极参与
2. **提供可持续资源** — 培训后为专业人员提供本地资源清单（Arc 分会、自闭症组织等）
3. **推动系统性变革** — 不要只停留在个别案例的应对上

## 总结要点

| 要点 | 说明 |
|------|------|
| 预防文化 | 从被动应对转向主动预防，减少危机发生 |
| 三大改革 | 减少不必要警察接触、改善紧急服务、确保有效沟通 |
| Pathways to Justice | 跨学科培训+社区行动方案，系统性解决问题 |
| 沟通是关键 | 大多数问题如果有良好沟通本可以避免 |
| 数据触目惊心 | 4–10% 监狱人口有智力/发育障碍，青少年系统高达 70% |
| 进步已有，任重道远 | 部分警局已制定政策，但全国性变革仍需努力 |

> "这个议题之所以如此引人关注，是因为它触及自闭症人士生活的方方面面。" — Leanne Davis
