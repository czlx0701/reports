# Teens and Screens — SPARK webinar 中文解读

**讲者:** Cheryl Cohen — 医疗传播专家、网页内容策略师、用户体验研究员；Interactive Autism Network (IAN)
**视频标题:** Teens and Screens
**时长:** 约45分钟
**链接:** https://www.youtube.com/watch?v=HOc1Qp31PCI

---

## 一、演讲框架

Cheryl Cohen 受 SPARK 和 IAN 邀请，分享一项面向家长的**80题问卷调查**结果，探讨自闭症青少年如何使用科技产品，以及家长的关切和应对策略。调查涉及三个群体：
- **ASD 平均组**（ASD Average）：自闭症青少年，家长报告其阅读/语言/智力能力在平均水平以上
- **ASD 低功能组**（ASD Low）：自闭症青少年，认知/语言/阅读能力低于平均水平
- **典型发育组（TD）**：84名典型发育青少年

---

## 二、"残疾"的社会模型

Cheryl 引入一个重要概念：

> **残疾 = 能力 + 障碍**
> 残疾不是个人的缺陷，而是个人能力与社会构造的世界之间的不匹配。

她举了一个生动的例子：罗斯福纪念公园中没有轮椅通道——即使是最强大的能力，遇上障碍就变成了残疾。这种视角贯穿整个演讲：科技产品是否造成了障碍？如何消除障碍？

---

## 三、青少年科技使用概况

### 全体青少年

- 2012年 Pew 研究中心：12–17岁青少年中，**短信超过任何其他沟通形式**，包括面对面交流
- 24% 的青少年"几乎持续在线"
- 2010年 Kaiser Family Foundation：8–18岁儿童每天使用媒体 **超7.5小时**（校外）
- **家长自己也日均使用屏幕近9.5小时**——"有插座的成人就有有插座的青少年"

### ASD 青少年的设备使用

- 几乎所有 ASD 青少年都使用**多种设备**
- ASD 低功能组使用的设备类型略有不同：
  - 传统电脑/笔记本更少
  - 触屏设备（如iPad）更多
  - 许多家长称 iPad 为"家庭必备设备"
- 以前低功能组使用昂贵的**专用辅助设备**，现在已被主流触屏设备替代

### ASD 青少年的应用程序使用

| 应用类型 | 发现 |
|---------|------|
| **自闭症专用 App** | 仅 **29%** 的 ASD 家庭报告使用（主要是图片沟通类 App）——远低于预期 |
| **办公生产力软件** | 所有组别都在使用，但 ASD 低功能组使用**更少**、**困难更多** |
| **娱乐应用（游戏）** | 几乎所有青少年都在使用——ASD 低功能组使用略少、困难略多 |
| **教育应用** | 各组无统计学差异 |

**结论：** 当应用针对特定受众（如简单的游戏）时，所有人都能使用；但通用生产力工具对低功能自闭症青少年构成**显著障碍**。

## 四、在线行为与安全关切

### 上网比例

- 几乎所有 ASD 青少年（除11%的ASD低功能组）都上网
- 不上网的原因：**无能力/无兴趣** 或 **家长禁止**

### 在线障碍

| 障碍类型 | 发现 |
|---------|------|
| **填写网络表单（Web Forms）** | ASD 低功能组困难最大——"这是一种隐含语言和社交惯例的对话" |
| **使用搜索引擎** | ASD 低功能组显著更困难——25%无法成功完成搜索 |
| **页面切换（Navigation）** | ASD 低功能组部分存在困难（类似老年人网页导航问题） |

### 家长主要关切

| 关切类别 | 具体内容 |
|---------|---------|
| **不良内容** | 脏话、暴力、血腥、色情——"最大关切" |
| **时间过长** | "花太多时间在屏幕上"——家长普遍反映 |
| **不良判断** | 意外购买、泄露个人信息、签署不该签的订阅 |
| **网络欺凌** | 15–25% 报告发生过——各组无显著差异 |
| **屏幕使用与睡眠** | 50–80% 的谱系儿童有睡眠问题，屏幕使用进一步加剧 |

## 五、游戏行为

- 游戏是**最大的问题领域**之一
- **男性是最大风险因素**——分离 ASD 和智力水平后，男性性别仍然最重要
- 研究（Mazurek & Engelhardt）发现：ASD 男孩比典型发育男孩花更多时间玩游戏
- 家长描述的问题：
  - "如果拿走设备就会 meltdown"
  - "上瘾了"
  - "玩的游戏暴力太多"
  - "运动/声音过度兴奋"
  - "社交游戏中透露太多信息"

### ASD 青少年的特殊困境

- **游戏太难、不渐进**——他们"必须立刻知道怎么玩"，否则极度沮丧
- **无法在任意时间保存/退出**——失去进度会引发强烈情绪
- **内容两级化**：要么看暴力/色情内容，要么看远低于年龄的儿童节目（反复看同一片段 → stimming）

## 六、给家长的建议

### 行为策略

1. **与青少年合作制定替代活动清单**——游戏/上网以外的可选项
2. **建立行为奖励系统**：用自然激励（positive reinforcement）鼓励替代行为
3. **若自己无法建立系统，寻找行为导向的心理健康治疗师**
4. **以身作则（Modeling）**：家长自己的屏幕使用习惯会被模仿——"有插座的成人，就有有插座的青少年"
5. **使用过滤和监控软件**——尽管很多家长反映这些软件"不好用"
6. **设置"无科技"时间**：如用餐时间、就寝前1小时

### 睡眠管理

- 保持卧室黑暗、安静
- 减少睡前屏幕使用（蓝光干扰褪黑素）
- 睡前避免兴奋性游戏/视频
- 建立可预测的睡前例行程序（对青少年同样重要）

### 沟通建议

- **参与青少年的电子生活（Be part of your teen's electronic life）**
- 讨论网络安全、网络欺凌的定义和形式
- 讨论**性教育**和**适当的在线内容**——包括法律后果（非法色情的严重性）
- 推荐资源：Tony Attwood 等人合著的书籍，Nick Dubin（一位有自闭症的成年人）的个人经历分享——"把脑袋埋在沙子里太久，后果可能是毁灭性的"

### 教育与倡导

- 在学校 IEP 和过渡计划中加入**技术素养和职业培训**
- **确保女孩也获得技术教育和编程培训**——研究发现女孩对科技职业的兴趣与男孩相当，但实际接受技术培训的女孩**显著少于男孩**
- 倡导本地和全国政府官员支持家庭需求
- **向科技公司倡导**：要求产品更易用、更易通过家长控制调节、更适合认知差异的用户

---

## 七、总结

| 层面 | 要点 |
|------|------|
| 📱 **使用普遍** | ASD 青少年与同龄人一样广泛使用科技产品 |
| 🧩 **能力差异影响使用** | ASD 低功能组在生产力工具、网页表单、搜索等方面遇到更多困难 |
| ⚠️ **安全关切真实存在** | 不良内容、过度使用、网络欺凌、隐私泄露 |
| 🎮 **游戏成瘾风险更高** | 尤其男性 ASD 青少年——内容控制和时间管理是核心挑战 |
| 💤 **屏幕影响睡眠** | 50–80% 谱系儿童有睡眠问题，屏幕使用是重要因素 |
| 👩‍💻 **技术培训不足** | 尤其对女孩——兴趣不输男孩，培训机会严重不足 |
| 🛠️ **行为策略有效** | 替代活动、奖励系统、家长示范、监控软件、开放沟通 |

**核心信息：** 科技对自闭症青少年既是机遇也是挑战。他们与同龄人一样热爱科技，但面临更多障碍——网页可用性、在线安全判断、游戏成瘾倾向。家长需要通过**积极介入、开放沟通、行为管理和科技倡导**来帮助孩子安全、有效地使用科技产品。同时，社会和科技公司有责任消除数字鸿沟，让产品对认知差异更友好。
