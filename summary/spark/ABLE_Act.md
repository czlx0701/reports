## 概述

Stewart Spielman 深入解读了 **ABLE 法案**（Achieving a Better Life Experience Act，即"实现更美好生活体验法案"），该法案以 Stephen Beck Jr. 命名。ABLE 账户是为残障人士设计的税收优惠储蓄账户，允许他们为合格残障相关支出进行储蓄，同时不影响其享受 Medicaid、SSI 等按需经济审查的联邦福利项目的资格。Spielman 结合自己作为两位孩子（其中一位在自闭症谱系上）的父亲的经验，既从政策角度也从个人角度进行了阐述。

---

## 一、ABLE 法案的背景与起源

### 529 大学储蓄计划的启示

- **529 计划**（按《国内税收法》第 529 条命名）最早源于 1980 年代中期密歇根州的努力
- 1996 年通过联邦立法确立，用于支付大学/职业学校的学费及其他费用
- 投资增长免税，享有多种税收优惠

### 残障人士的储蓄困境

并非每个孩子都会上大学，而且许多残障人士（包括自闭症人士）有重大且持续的当前或预期支出：

- 许多自闭症人士依赖 **Medicaid** 和 **SSI（补充保障收入）**
- 这些是 **按需经济审查的福利项目**——即使少量储蓄也可能导致资格丧失
- 这形成了 **储蓄的逆向激励**——想为未来储蓄，却可能因此失去基本福利

### 立法历程

| 时间 | 里程碑 |
|------|--------|
| 2000 年代中期 | 倡导者开始围绕创建"529类比计划"凝聚共识 |
| 2014 年 | 作为《2014年税收增加预防法案》的一部分，国会通过、总统签署 **ABLE 法案** |
| 法案全称 | Stephen Beck Jr. Achieving a Better Life Experience Act of 2014 |

该法案以 **Stephen Beck Jr.** 的名字命名，他是一名残障人士的倡导者，在众议院通过后、参议院表决前不幸去世。Spielman 动情地回忆："他相信残障人士不应比非残障人士拥有更少的未来规划机会。"

## 二、ABLE 账户核心特点

### 基本定位

ABLE 账户可以理解为大学储蓄账户的"表亲"——相似但有重要区别：

### 税收优势

- **供款**: 使用税后资金（非税前）
- **投资收益**: 在账户内增长 **免税**
- **分配**: 用于合格残障支出的分配 **不征收联邦税**
- **州税处理**: 各州不同，部分州提供额外税收激励

### 福利保护（最关键的特点）

- ABLE 账户中的资金在确定 Medicaid 和 SSI 等按需经济审查项目资格时 **通常不予计入**
- 这消除了"储蓄等于失去福利"的困境

---

## 三、资格规则

### 基本条件

任何年龄的个体，只要在 **26 岁之前** 失明或出现残障，即可开设 ABLE 账户。

> **重要提示**: 关键不是 **诊断时间**，而是 **残障发生的时间**。因此，一个人在 26 岁之后才获得自闭症诊断，仍可能有资格——只要残障条件在 26 岁前已经存在。

### 资格认定途径

| 途径 | 说明 |
|------|------|
| **自动合格** | 已领取 SSI 或 SSDI（社会保障残障保险） |
| **同情津贴条件** | 社会保障署列出的快速认定条件（ASD/自闭症谱系障碍在其蓝皮书中列出） |
| **医生认证** | 医生书面证明：个体失明或患有医学上可确定的躯体/精神损伤，导致严重功能限制，预计持续不少于 12 个月或导致死亡 |

### SSA 蓝皮书对 ASD 的标准

需要医疗文件证明：
- 语言交流、非语言交流和社会互动方面的质性缺陷
- 显著受限的重复行为模式、兴趣或活动
- 以下一个领域的极度受限或两个领域的显著受限：
  - 理解、记忆或应用信息
  - 与他人互动
  - 专注、坚持或维持节奏
  - 适应或管理自我

## 四、SSI 与 Medicaid 的具体规则

### SSI（补充保障收入）

| 情况 | 规则 |
|------|------|
| 账户余额 ≤ $100,000 | 不计入资源，不影响 SSI 资格 |
| 账户余额 > $100,000 | 超出部分计入资源，可能导致 SSI 福利 **暂停**（但 **不丧失** 资格） |
| 合格残障支出分配 | 一般不计数 |
| **住房支出分配** | 如果收到月份未使用、保留至下月，则可能计入资源 |

### Medicaid

- ABLE 账户余额 **完全不计入** Medicaid 资格认定
- 合格残障支出分配的用途不影响 Medicaid
- 各州按需经济审查项目可能存在差异，需查询所在州法律

---

## 五、账户管理与投资规则

### 所有权

- ABLE 账户由 **残障受益人本人所有**（与 529 计划不同——大学生可以不是账户所有人）
- 如受益人是未成年儿童或无法管理账户，可由 **签署授权人**（父母、法定监护人或授权委托代理人）开设并管理

### 供款规则

| 规则 | 说明 |
|------|------|
| **谁可以供款** | 任何人——受益人本人、父母、雇主、朋友均可 |
| **供款形式** | 必须是现金 |
| **年度限额** | 等同于联邦赠与税免税额（2017年为 **$14,000**） |
| **总限额** | 参照所在州 529 计划的总限额（各州不同，有的允许超过 $500,000） |
| **账户数量** | 每人 **只能有一个** ABLE 账户（与 529 不同，后者允许多个） |

### 开设地点

- 可以在 **任何开设了 ABLE 计划的州** 开设
- 不限于居住州——可在全国范围内选择最佳计划
- 各州有权自主决定是否推出 ABLE 计划（并非强制）

---

## 六、合格残障支出 (Qualified Disability Expenses, QDE)

### 定义

与受益人失明或残障相关、为受益人利益、旨在维持或改善其独立生活、健康或生活质量的支出。

### 具体类别

ABLE 法案明确列出的支出范围广泛：

- **教育**: 学费、书本费、相关费用
- **住房**: 房租、房贷等（注意 SSI 特殊住房规则）
- **交通**: 车辆购置、改装、交通服务
- **就业培训**: 职业教练、职业技能培训
- **辅助技术**: 沟通设备、辅助器具
- **个人支持服务**: 个人护理助手、喘息服务
- **医疗/健康**: 自付医疗费用、治疗、处方药
- **财务管理/行政管理**: 法律费用、财务规划
- **其他**: 任何经 IRS 认定的与残障相关的支出

### 违规分配

如分配用于非合格残障支出：
- 收益部分需缴纳 **联邦所得税**
- 另加 **10% 罚款**

---

## 七、州级实施与全国现状

- 各州自行决定是否实施 ABLE 计划（不强制）
- 已推出计划的州：各州方案在费用结构、投资选项、税收优惠等方面存在差异
- Spielman 建议：访问各州 ABLE 网站，信息清晰易懂
- 联邦法律框架统一，但 **州级按需经济审查项目** 的处理可能不同——务必检查所在州法律

---

## 总结要点

| 要点 | 说明 |
|------|------|
| ABLE = 残障版 529 | 税收优惠储蓄账户，为合格残障支出储蓄 |
| 福利保护 | 不影响 Medicaid/SSI 资格——解决了"储蓄陷阱" |
| 年龄限制 | 残障须在 26 岁前发生（非诊断时间） |
| 年度限额 | 2017 年为 $14,000（等于联邦赠与税免税额） |
| 账户数量 | 每人仅限一个 ABLE 账户 |
| 合格支出广泛 | 教育、住房、交通、医疗、辅助技术等 |
| 全国可开户 | 可在任何开设 ABLE 计划的州开户 |
| 核心精神 | "给予残障人士与非残障人士同等的未来规划机会" |

> "ABLE 法案就是关于公平——确保我的两个孩子（一个在谱系上、一个不在）拥有同样好的未来规划机会。" — Stewart Spielman
