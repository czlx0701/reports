## 一、开篇：行为干预优先

Dr. Yerys 的开场核心信息：**行为干预永远优先于药物**。

- 早期高强度行为/发育干预（如 Early Start Denver Model，每周 12–40 小时）有**强证据**支持，能显著提升 IQ（>15 分）、语言和适应功能
- 社区治疗组的儿童也会进步，但大学诊所组进步更大
- **药物不能替代行为干预**

---

## 二、证据概览：干草堆中的针

Dr. Yerys 形容自闭症药物研究为"**不确定性干草堆中的针**"——大部分我们想知道的，我们都还不知道。

### 已证实的证据层级

| 层级 | 描述 |
|------|------|
| **FDA 批准** | Risperidone 和 Aripiprazole — 用于**易激惹（irritability）**，不是治疗自闭症本身 |
| **多项 RCT 一致** | ADHD 药物（兴奋剂/非兴奋剂）在自闭症中的证据 |
| **单一大型 RCT** | Guanfacine ER、Melatonin PR |
| **单一阳性 pilot** | Sulforaphane、NAC — 需更大研究验证 |
| **证据混合/阴性** | SSRIs（混合结果）、Oxytocin（大型阴性）、Memantine（阴性） |
| **不合理治疗** | Chelation（螯合疗法）、干细胞输注 |

---

## 三、FDA 批准的药物：Risperidone 和 Aripiprazole

- 唯一 FDA 批准用于自闭症的药物，但批准适应症是**易激惹、攻击、自伤**
- 不是用于自闭症核心症状
- 大多数效果在**前 4 周内**出现
- 有效率约 **75%**（临床医生评定）
- **主要副作用：** 体重增加（最令人担忧）、镇静、运动障碍风险
- **Metformin 可抵消体重增加** — 效果在 8–16 周后显现

---

## 四、ADHD 药物在自闭症中的应用

### 兴奋剂（Stimulants）

- Methylphenidate（利他林/Ritalin）— **"50 法则"**：约 50% 被评定为显著改善，症状减少约 30%
- **重要：** 自闭症儿童更易出现副作用，尤其是**易激惹和激动加重**
- 近 20% 无法耐受最低剂量

### 非兴奋剂

- **Atomoxetine（Strattera）：** 最初研究反应率仅 21%（vs 9% 安慰剂），较高剂量（1.8mg/kg，分次给药）后反应率接近 50%
- **Guanfacine ER（Intuniv）：** 50% 改善率（vs 10% 安慰剂），副作用包括镇静、食欲减退、口干 — **必须监测血压**

---

## 五、单一阳性研究的药物

### 褪黑素缓释剂（Prolonged-release Melatonin）

- 欧洲可用，美国无 FDA 批准
- 显著改善**总睡眠时间**和**入睡时间**
- 普通短效褪黑素可帮助入睡，但**不增加总睡眠时间**（入睡更早 → 醒得更早）

### Sulforaphane（西兰花芽提取物）

- Pilot 研究（40 人）显示阳性结果
- **后续大型研究完全阴性**
- 需要更大规模研究验证

### NAC（N-乙酰半胱氨酸）

- 非处方补充剂
- 一项 pilot 显示对易激惹/激动有帮助
- 注册成分不稳定，数据有限

---

## 六、混合/阴性证据

### SSRIs（选择性5-羟色胺再摄取抑制剂）

- Citalopram 大型 RCT：对**重复行为无益处**
- 在症状较轻的儿童中，安慰剂效果反而更好
- 副作用：**激活效应（activation）** — 精力增加、睡眠减少、冲动、情绪快速波动
- 成人中，Fluoxetine 对 OCD 症状有效
- **自闭症焦虑/情绪障碍的药物研究严重不足**

### Oxytocin（催产素）

- 单剂量实验室研究显示可改变社会行为（cyberball 游戏范式）
- **大型安慰剂对照 RCT（Lynn Sikich 领导）——完全阴性**
- 长期使用 oxytocin 不比安慰剂好

### Memantine（Namenda）

- 大型研究显示**与安慰剂无差异**

### Lurasidone（Latuda）

- 同类药物但两个剂量均未优于安慰剂

## 七、"不合理治疗"区域

Dr. Yerys 称之为"粪堆"（dung heap）：
- **Chelation（螯合疗法）：** 曾有儿童死亡案例
- **脐带血/干细胞输注：** 极其昂贵、自费、常在国外进行；已有 RCT 显示**无益处**
- **大麻/CBD：** 焦虑短期有安慰剂反应；CBD 与安慰剂直接对照无差异；THC 有长期认知风险和精神病风险

---

## 八、何时考虑用药：核心决策框架

Dr. Yerys 的临床决策路径：

### 第一步：安全评估
1. **有人正在受伤或可能受伤吗？**（不总是显而易见的）
2. **孩子是否可能失去教育/其他环境？**

### 第二步：寻找触发因素（医学优先）
- **疼痛** — 最常见原因
- **感染/牙痛/头痛/耳部感染**
- **癫痫** — 青少年期有第二个高峰
- **便秘** — 极其常见，可导致大便渗漏（streaks in underwear）
- **药物变化** — 新药（如伪麻黄碱）可能触发行为问题
- **环境创伤/压力源**

### 第三步：沟通与行为干预
- 视觉日程表、PECS（图片交换沟通系统）
- 功能性行为分析（FBA）：找出行为的**功能**——获得物品/逃避任务/感觉刺激
- **强化适当沟通行为**，不再强化问题行为
- 家长培训效果显著

### 第四步：共病精神障碍诊断
- ADHD、焦虑障碍、OCD、抑郁
- **明确诊断才能针对性治疗**

### 第五步：FDA批准药物的使用指征
- 只有在上述路径都走完后，才考虑 Risperidone/Aripiprazole
- 核心问題：**是否有显著冲动成分？** 如果有，先试 ADHD 药物

## 九、临床案例：Janna

7 岁女孩，ASD + ADHD + 焦虑：

- 表现：ADHD 症状、学校问题、焦虑、捏母亲（留下淤青）
- 既往用药失败：Methylphenidate（引起易激惹）、Guanfacine（血压未监测 → 晕厥）、Citalopram（激活效应）
- **非药物干预：** 视觉日程表、PECS、短期奖励系统替代全天惩罚
- **药物调整：** Guanfacine 改为睡前给药（利用镇静作用）
- 沟通和行为改善后，不再需要 Atomoxetine 或抗精神病药

**核心教训：** 优化沟通和行为支持后，很多情况下根本不需要加药。

## 十、Q&A 精选

**Q: 药物引起的创伤和 PTSD？**
A: 创伤更多来自**约束、强迫用药、急诊室经历**，而非药物本身。应尽一切可能避免强迫给药。

**Q: 药物基因组学（基因检测指导用药）？**
A: 在自闭症中**几乎没有用处**，更多时候反而干扰正确治疗。唯一例外：lamotrigine/carbamazepine 在亚裔人群中需检测特定 HLA 基因。

**Q: 青春期和药物的关系？**
A: 体型增长 > 青春期本身的影响。当孩子变得比父母大时，之前可管理的行为变得危险。但同时，青春期后 ADHD 症状可能自然减轻。

**Q: 焦虑的治疗？**
A: 自闭症焦虑的药物证据严重不足。改良 CBT（认知行为疗法）是首选。正在进行的 Sertraline（Zoloft）加拿大试验值得期待。

**Q: CBD 对自闭症的效果？**
A: 缺乏证据。焦虑本身对安慰剂反应良好。THC 有长期认知和精神病风险，应谨慎。

## 十一、总结

| 层面 | 要点 |
|------|------|
| ✅ **行为干预优先** | 药物永远不能替代早期强度行为干预 |
| ✅ **FDA药物有效但有代价** | Risperidone/Aripiprazole 对易激惹有效，但需警惕体重增加 |
| ⚠️ **ADHD药物"50法则"** | 约 50% 有效，但副作用更常见 |
| 🔍 **医学原因排查第一** | 疼痛、便秘、癫痫是行为恶化的常见诱因 |
| 🧩 **明确共病诊断** | 区分焦虑、ADHD、OCD 才能精准用药 |
| 🚫 **证据簿弱的领域多** | SSRI 焦虑、Oxytocin、CBD 等均缺乏可靠证据 |
| 👪 **家长是关键** | 视觉支持、沟通策略、正向强化比药物更重要 |

**核心信息：** 用药不是第一步，而是**走完所有其他路径后的选择**。在"干草堆"般的不确定性中，每个决策都应从"医学优先、行为次之、药物最后"的原则出发。
