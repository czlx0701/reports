## 一、引言：两种截然不同的观点

Dr. Goin-Kochel 以一个引人深思的对比开场：
- **观点A（某同事）：** "几乎所有自闭症儿童都会经历 regression（技能倒退）"
- **观点B（另一同事）：** "Regression 正在逐渐被淘汰——它其实没那么重要"

为何在同一领域会有如此大的分歧？答案在于**定义不同**和**方法不同**。

## 二、Regression 的定义与历史回顾

### 基本定义

- **字典定义：** 回到先前的位置或状态
- **研究定义：** **失去先前已获得的技能**（loss of previously acquired skills）

### 历史里程碑

| 时期 | 关键发现 |
|------|---------|
| **1943** | Kanner 原始11例报告中，一位母亲描述孩子"gotten backward mentally"（智力倒退） |
| **此后50年** | 陆续有语言丧失（language loss）伴预后更差的报告；流行病学研究发现约1/3自闭症儿童有技能丧失 |
| **1970s–1990s** | 明确描述语言丧失伴随发育停滞和ASD症状出现；但仍有人质疑 regression 的真实性 |
| **2000–2010** | 大量研究涌现——约1/3儿童在平均 **21个月** 时出现技能丧失 |

### 重要方法论突破

1. **家庭录像研究（Video Studies）：** 研究者与家长合作回顾家庭录像，发现有些被家长认为"一直正常发育"的儿童，在技能丧失前其实已存在早期自闭症症状
2. **前瞻性临床评分研究（Prospective Clinician-Rated Study）：** 2010年发表，对25名后来确诊自闭症的婴儿从6个月跟踪到3岁，**86%** 显示出显著**下降的发展轨迹**

### 前瞻性研究的启示

- 差异非常微小（如**每分钟注视次数从3次降到2次**）——家长很难注意到
- 作者结论：**大多数ASD儿童在症状出现时都经历着 regression**（技能下降，而非完全丧失）
- 但回顾性报告（parent report）的 regression 率仅约1/3——说明**回顾性报告漏掉了大量细微的技能下降**

## 三、Regression 的异质性（Heterogeneity）

ASD 本身是异质性的，regression 在 ASD 中同样是异质性的，表现在：

| 维度 | 变化范围 |
|------|---------|
| **技能类型** | 语言、社交、游戏、运动、自理 |
| **下降速度** | 急骤丧失（acute/abrupt） vs 缓慢渐进（gradual） |
| **广泛性** | 单一领域（仅语言） vs 全面性（global） |
| **丧失性质** | 作为ASD标志症状 vs 作为ASD起病的一部分 |
| **持续时间** | 数周、数月 vs 2–3年 |
| **先前的掌握水平** | 仅有单音/单词 vs 完整句子 |
| **病因** | 目前仍不明确——**这是最不了解的领域** |

## 四、2010年后的研究进展

### 2010–至今：回顾性研究的持续

- 大多数研究依赖**回顾性家长报告**（常用 ADI 访谈）
- 2019年一项**75项研究的荟萃分析**（33,000+参与者）：
  - 约 **30%** 报告有 regression
  - 平均发生年龄约 **19.8个月**
  - **作者呼吁：需对 regression 形成统一定义并开发标准化测量工具**

### 国际工作组：SIG on Regression/Skill Loss

- Dr. Goin-Kochel 是国际自闭症研究学会（INSAR）的 regression 专题兴趣小组（SIG）成员
- 由 Dr. Katrina Williams 和 Shirona Mara 领导
- 三年计划：制定操作定义、统一数据标准、开发评估工具
- **正在招募有亲身经历的自我倡导者和家属加入**

## 五、研究 Regression 的重要性

### 维度一：医疗与功能结局

| 预后指标 | 有 regression 的儿童 |
|---------|-------------------|
| 共病精神科诊断 | 更常见 |
| 睡眠问题 | 更常见 |
| 癫痫 | 可能更常见（证据不一） |
| 认知/IQ | 结果不一——部分研究显示较低，部分无差异 |
| 适应功能 | 结果不一 |
| ASD 症状严重度 | 多数研究无显著差异 |

#### 关键研究：#39Simon Simplex Collection 2014

- 使用 ADI 标准 + 额外测量捕捉更细微的技能丧失
- **语言丧失（Language loss）：** 有丧失的儿童在所有功能指标上略低于无丧失的儿童
- **非语言丧失：** 仅"完全丧失"组 vs "无丧失"组有显著差异——亚阈值丧失（sub-threshold）介于两者之间

#### 2022年最新研究（500名幼儿病历回顾）

- 采用**临床医生记录**的 regression 定义
- 只有 **4%** 符合标准——再次证明了不同定义导致截然不同的发生率
- 但与2014年结果一致：有 regression 的儿童语言和适应功能得分更低

#### 长期预后：有希望的结果

- **Pathways in ASD 研究**（400名儿童，追踪至10岁）：
  - 22% 有语言丧失
  - 到10岁时，有语言丧失的儿童仅比无丧失者**落后约3个月的语言水平**
  - 作者结论：语言丧失对长期结局的影响是**有限的（diminished impact）**

#### SPARK 数据（2015–2021）

- **儿童**：~32% 有语言丧失，~65% 语言能力恢复
- **成年受抚养者**：~31% 有语言丧失，~63% 语言能力恢复
- **其他技能（社交、游戏等）**：丧失率较低，恢复率也较低（约33–34%），可能是因为社交技能本就是 ASD 的核心特征

### 维度二：家长认知与治疗选择

#### 家长对病因的信念

- 早期研究：报告 regression 的家长更倾向于相信**外部环境因素**（最常见：疫苗）是 ASD 的原因
- 2014 SSC 研究（2,500+家庭）：
  - 有 regression 的家庭更倾向于认为**毒素、疫苗、环境污染**是原因
  - 无 regression 的家庭更倾向于归因于**遗传因素**

#### 疫苗犹豫（Vaccine Hesitancy）

- 有 regression 的家长疫苗犹豫比例更高
- SPARK 调查（225个家庭）：29% 家长为疫苗犹豫者；这些家庭的孩子更常为非头胎、症状更重、更常有 regression/发育平台期
- 但 SSC 数据发现：**实际疫苗接受率在各 ASD 起病类型之间无显著差异**——即虽然有 regression 的家长更担心疫苗，但并未显著影响实际的接种行为

#### 治疗选择

- 有 regression 的儿童：**44.7% 从未使用过早期密集行为干预（EIBI）**
- 但**44.7% 使用过生物医学/替代疗法**（vs 无 regression 组的 ~20%）
- 治疗类型分析发现6种治疗类型模式，其中两类在回归组比例更高

## 六、给家长的建议

如果怀疑孩子出现技能丧失：

| 建议 | 说明 |
|------|------|
| 📋 **立即评估** | 找专业医生进行全面的发育评估 |
| 💡 **考虑早期密集干预** | 对技能丧失儿童应尽快启动干预 |
| 🔬 **追踪医学原因** | 少数持续丧失或进行性丧失的儿童可能需要医学排查（如代谢、神经） |
| 💊 **警惕替代疗法** | 有 regression 的家长更倾向于尝试螯合（chelation）等未经证实的疗法——可能有害 |
| 💉 **信任疫苗科学** | 大量证据表明疫苗与 autism 无关；延迟/拒绝疫苗使儿童面临疫苗可预防疾病的风险 |
| 🤝 **加入研究** | SIG 正在招募有亲身经验的家庭，推动更统一的 regression 定义和更好的测量工具 |

## 七、总结与展望

| 层面 | 要点 |
|------|------|
| 📊 **发生率因定义而异** | 家长报告 ~30%，前瞻性研究 ~86%，临床记录仅4% |
| 🧩 **高度异质** | 类型、速度、广泛性、持续时间各不相同 |
| ✅ **预后并非悲观** | 大多数儿童（~92%语言恢复）能重新掌握丧失的技能 |
| 🔍 **研究意义重大** | 影响家长对病因的认知、治疗选择、疫苗行为 |
| 🌍 **国际协作进行中** | SIG 工作组致力于统一定义和标准化工具 |
| 🚨 **关注小部分持续丧失者** | 可能代表不同的病因机制，需要专项干预 |

**核心信息：** Regression 在自闭症中极为常见，但常被漏报。其定义高度依赖测量方法。好消息是大多数孩子最终能恢复丧失的技能。研究 regression 不仅能帮助我们理解 ASD 的病因异质性，还能指导家长做出更明智、更安全的治疗决策。
