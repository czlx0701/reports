> **平台：** SPARK 研究网络研讨会

## 概述

Tisha Turner 在本讲座中系统介绍了自闭症中显著的 **性别偏差（sex bias）** 现象——男性与女性患病比例约为 **4:1**，并从遗传学角度深入探讨了背后的机制，特别是**女性保护效应（Female Protective Effect）**。她展示了自己团队基于 de novo DB 数据库、近 9,000 个亲子三人组（trio）的最新研究，揭示了基因发现率在男女性之间的差异及其生物学意义。

---

## 一、自闭症的流行病学与遗传学背景

### 基本数据
- 自闭症是一种**儿童神经发育障碍**（childhood neurodevelopmental disorder）
- **遗传度约 80%**
- **患病率**：约 1/59
- **性别比**：4:1（男性:女性），即约 80% 的自闭症患者为男性

### 遗传学研究进展

#### 1990 年代：单基因综合征
- **脆性 X 综合征**（Fragile X Syndrome）→ FMR1 基因
- **Rett 综合征** → MECP2 基因
- FMR1 位于 X 染色体，主要影响男孩

#### 常见变异（Common Variation）
- 全基因组关联研究（GWAS）和多基因风险评分（PRS）
- 总体贡献率可达 **50%**
- 目前仅有 **5 个**全基因组显著位点——还有大量工作要做

#### 罕见变异（Rare Variation）——目前最大的突破来源
- **拷贝数变异（CNV）**：DNA 片段的缺失或重复
- **新发基因破坏突变**（De Novo Gene-Disrupting Mutations）
- 目前最可靠的自闭症基因列表约 **124 个**
- 可进行基因型-表型关联分析（genotype-phenotype correlations）

## 二、性别偏差：现象与可能机制

### 性别偏差并非自闭症独有

DSM-5 中多种障碍存在性别偏差：

| 偏向女性 | 偏向男性 |
|---------|---------|
| 神经性厌食症（仅 9% 为男性） | 智力障碍（57% 男性） |
| | **自闭症（80% 男性）** |

### 易感性分布模型（Liability Distribution）

1960 年代提出的概念：每个人都有一定水平的**易感性总和**（遗传+环境因素）。当超过某个**阈值**（tau）时，即发展为该表型。

**引入性别后**：
- 男性的阈值**较低**
- 女性的阈值**较高**
- 阈值差异导致在同样的遗传和环境负荷下，男性更容易发展为自闭症

### SHIP 模型 —— 潜在生物学原因的速记法

| 字母 | 含义 | 说明 |
|------|------|------|
| **S** | Sex Chromosomes（性染色体） | 女性 XX，男性 XY；X 染色体存在逃逸失活现象 |
| **H** | Hormones（激素） | 雌激素、雄激素、睾酮等 |
| **I** | Imprinting（印记） | 性别特异性基因组印记 |
| **P** | Protective Effect（保护效应） | 女性需要更大的突变负荷才会患病 |

### 女性保护效应（Female Protective Effect）

核心假设：**女性需要更严重或更多的突变才能达到自闭症诊断标准。** 因此，被诊断为自闭症的女性往往携带更"强力"的遗传变异。

---

## 三、女性保护效应的证据（历年研究）

| 年份 | 研究者 | 发现 |
|------|--------|------|
| 2011 | Levy 等 | 女性自闭症患者中有更高频率的新发 CNV |
| 2012 | Neale 等 | 女性自闭症患者中新发变异率更高 |
| 2013 | Robinson 等 | 女性自闭症患者的兄弟姐妹中自闭症特征更多 |
| 2014 | Jacquemont 等 | 女性神经发育障碍中有害 CNV 负担更重 |
| 2015 | （Tisha 团队） | 女性富集的多个家庭中新基因发现率更高 |
| 2015 | Sanders 等 | 重复验证了女性 CNV 负担更重的发现 |
| 2019 | Doan 等 | 女性有更多隐性遗传的基因破坏（新范式） |

所有证据一致指向：**女性需要更严重的大效应罕见变异才能发展出自闭症。**

## 四、Tisha 团队的新研究

### 研究问题

1. 是否有基因**仅在某一性别中**显著？
2. 基因发现率在男女之间是否有差异？**女性的基因发现率是否更高？**
3. 直接比较男性和女性时，是否有基因的 de novo 变异计数存在差异？

### 数据来源

**发现队列**：de novo DB 数据库 v1.5
- 近 **9,000 个**测序亲子三人组（26,475 人）
- 包括自闭症、智力障碍、发育障碍（统称为神经发育障碍，NDD）
- 性别比：2.2（男性:女性）

**复制队列**：GeneDx 提供的 **18,778 个**额外三人组（56,000+ 人）
- 性别比：1.2

### 统计方法

**两种标准的基因显著性检验模型**：
1. **黑猩猩-人类模型**（Chimpanzee-Human Model）：基于物种间比较，判断某基因的突变是否多于随机预期
2. **De Novo TADA**：基于序列内容统计，判断突变是否超预期

**直接比较方法**：
- **Fisher 精确检验**：直接比较男性和女性之间每个基因的 de novo 变异计数
- **降采样分析（Downsampling）**：从男性子集中随机抽取与女性样本量相同的子集，反复 10,000 次，比较基因发现率

## 五、主要发现

### 发现队列结果

| 分组 | 显著基因数量 |
|------|------------|
| 仅女性显著 | 36 个 |
| 仅男性显著 | 37 个 |
| 两者均有 | 19 个重叠 |
| 总计 | 54 个 |

**关键洞察**：女性样本量仅为男性的一半（~2,779 vs ~6,000），但发现的基因数量几乎相同 → **女性基因发现率更高**

### 降采样分析

- 从 6,000 名男性中随机抽取 2,779 人，重复 10,000 次
- 女性发现的 36 个基因**从未**在降采样的男性子集中达到
- **统计学显著**：女性能发现更多基因

### 复制队列结果

| 分组 | 显著基因数量 |
|------|------------|
| 仅女性显著 | 22 个 |
| 仅男性显著 | 18 个 |
| 两者均有 | 15 个重叠 |
| 总计 | 25 个 |

复制队列延续了相同的模式。

### 性别偏差可能由表型驱动

- 女性自闭症患者更常伴有**发育障碍/智力障碍**
- IQ 分析显示研究内女性自闭症患者 IQ **低于**男性
- 这与之前的研究一致（Iosef 等 2014）
- 提示女性保护效应可能部分通过更严重的认知损伤体现

## 六、X 染色体的特殊作用

### 仅女性显著的 4 个基因

经过严格的多重检验校正，**4 个基因仅在女性中达到显著**：
1. **DDX3X**
2. **HDAC8**
3. **NAA10**
4. **USP9X**

**全部位于 X 染色体上**。

### X 染色体逃逸失活（X Inactivation Escape）

- 女性有两条 X 染色体，但通常只有一条活跃（另一条被沉默）
- 约 **13%** 的 X 染色体基因可**逃逸这种失活**——两条染色体都表达
- 这 4 个基因中，**3 个是 X 失活逃逸者**

**DDX3X 的示例**：
- GTEx 数据库显示：DDX3X 在女性中的表达水平**显著高于男性**（在大脑、心脏、肝脏等组织一致）
- 意味着女性有"缓冲"（buffered expression）——两条染色体同时表达

### 与脆性 X 综合征的不同

- 脆性 X 综合征（FMR1）：女性虽有变异但通常**不表现出综合征**，男性则严重受影响
- 本研究发现的这 4 个基因：在女性中**确实观察到突变和疾病**，而在男性中几乎从未见到
- 推测：男性中这些基因的突变可能过于严重，以致胚胎难以存活

### 这些基因的已知临床表型

| 基因 | 相关疾病 |
|------|---------|
| USP9X / DDX3X | 女性智力障碍 |
| WDR45 | 脑铁积累性神经变性（主要影响女性） |
| HDAC8 | Cornelia de Lange 综合征（男性智力障碍更严重） |
| NAA10 | Ogden 综合征（影响男女） |

## 七、男女直接比较：唯一的差异基因

### Fisher 精确检验结果

在发现队列和复制队列中，**只有一个基因在男女之间达到统计显著差异**：

> **DDX3X**

- 发现队列：男性 0 例 vs 女性 26 例变异
- 复制队列：男性 2 例 vs 女性 65 例变异
- 极显著（p 值极低）

### 名义显著（Nominal Significance）的基因

如果使用更宽松的显著性标准，另外 **3 个基因**出现在名单中：
- **MECP2**（Rett 综合征相关）
- **NAA10**（Ogden 综合征）
- **HDAC8**（Cornelia de Lange 综合征）

全部位于 X 染色体。

### 功率分析（Power Analysis）

- 新增 10,000 个三人组仍只能发现 DDX3X 这一个差异基因
- 需要到 **50,000 个额外三人组** 才能发现 3 个新的差异基因
- 即使发现更多差异，效应量也非常小

### 核心结论

> **虽然基因发现率（rate）在男女之间存在差异，但所发现的基因本身没有太大差异。** 大多数基因在男女性中都有作用，只是女性需要更强的遗传信号才能进入分析。

## 八、从基因到生物学：基因调控网络

### 女性显著基因的生物学功能

- 主要参与**转录调控和染色质结合**（Transcriptional Processes / Chromatin Binding）
- 这是自闭症遗传学中反复确认的核心生物学通路之一（另一条是突触功能）

### 蛋白-蛋白相互作用网络

- 女性中发现的 22/25 个显著基因的编码蛋白质位于**同一个相互作用网络**中
- 这些蛋白质主要定位在**细胞核**，作为**关键调控因子（Key Regulators）**
- 它们调控其他下游基因的表达 → 破坏这些基因产生更广泛的生物学效应

### 推测模型

- 女性发现的基因更可能是网络中的"A 类基因"——**有广泛下游效应的主调控因子**
- 男性发现的基因可能是"B 类基因"——**只有局部效应**
- 这解释了为什么破坏这些基因女性会产生更严重的表型

### 细胞类型富集

- 这些基因在**皮层神经元**（特别是抑制性和兴奋性神经元）中显著富集
- 在非神经细胞类型中富集程度较低
- 确认这些基因在神经发育中的重要作用

## 九、总结与未来方向

### 核心结论

1. **性别偏差**是评估表型时的重要考量因素——也存在于其他障碍中
2. 基于大效应罕见变异的**女性基因发现率更高**（与女性保护效应一致）
3. 女性研究发现可揭示 X 染色体及其失活逃逸机制的重要新见解
4. 女性显著基因多为**染色质调控因子**和**主调控基因**
5. 大多数已发现的自闭症基因在男女性中**都存在**，只是发现率不同

### 未解决的问题

- Y 染色体在自闭症中的潜在作用（尚未构建好基因模型）
- 遗传性变异（常见和罕见）对性别偏差的贡献
- 大量非遗传因素仍需探索
- 临床诊断工具是否存在对女性的**漏诊偏差**（ascertainment bias）？

### 关于 SPARK 的展望

- Tisha 的研究目前未使用 SPARK 数据（当时尚未有数据）
- SPARK 基因组学联盟正在进行新数据集的类似分析
- SPARK 的开放招募模式可能提供对性别偏差更完整的理解
