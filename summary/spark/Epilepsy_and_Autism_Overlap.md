## 一、引言：两个领域的交汇

Dr. Cook 作为儿童神经科医生出身，后专攻行为神经科与自闭症，是罕见同时深耕两个领域的专家。

**核心概念：** 癫痫（epilepsy）与自闭症之间存在显著重叠，但两者之间的关系**复杂且尚不明确**。

### 三种可能的关系模型

1. **因果模型（Causal）：** 自闭症导致癫痫，或癫痫导致自闭症
2. **附带现象（Epiphenomenon）：** 两者同时出现，但一方不导致另一方——源于共同的脑发育差异
3. **共病模型（Co-occurrence）：** 共享遗传和环境风险因素

目前证据更支持**附带现象/共病模型**。

## 二、基本定义

### 癫痫发作（Seizure）
- **定义：** 大脑正常电活动的突然中断，伴随意识改变和/或其他神经行为表现
- 大脑通过**电信号**在神经元之间、跨突触传递信息
- 癫痫发作时，神经元群**同步异常放电**

### EEG（脑电图）
- 测量大脑电活动的工具（类似于心脏的 ECG）
- 电极放在头皮上记录脑电波
- 用于诊断癫痫、确定发作类型

### 癫痫（Epilepsy）
- **定义：** 两次或以上非诱发性癫痫发作
- 单次发作 ≠ 癫痫（可能由发烧、低血糖等诱发）
- 诊断需要结合临床表现 + EEG 证据

### 癫痫发作类型

| 类型 | 特点 |
|------|------|
| **全面性发作（Generalized）** | 累及全脑，意识丧失 |
| – 强直-阵挛发作 | 俗称"大发作"，全身僵硬+抽搐 |
| – 失神发作 | 短暂意识空白（数秒），看似"发呆" |
| – 肌阵挛发作 | 短暂肌肉抽搐 |
| – 失张力发作 | 肌肉突然松弛→摔倒 |
| **局灶性发作（Focal）** | 始于大脑局部区域 |
| – 单纯部分性 | 意识清醒，局部症状 |
| – 复杂部分性 | 意识受损，自动症（咂嘴、摸索） |
| – 继发全面性 | 从局灶扩散至全脑 |

## 三、患病率数字

| 群体 | 癫痫患病率 |
|------|-----------|
| **一般儿童人群** | ~1% |
| **自闭症群体（整体）** | ~10–30% |
| **自闭症+智力障碍** | 可达 **30–40%** |
| **自闭症-无智力障碍** | ~5–10% |
| **智力障碍-无自闭症** | ~15–20% |
| **特定遗传亚群**（如 Dup15q、CDKL5、TSC） | >50% |

**核心趋势：** 智力障碍程度越重，癫痫风险越高。女性自闭症中癫痫率略高于男性。

### 发病年龄双峰分布

- **第一峰：** 5 岁前（尤其 1–3 岁）
- **第二峰：** 青春期（与激素变化和脑重塑有关）

## 四、风险因素

### 智力障碍（ID）
- **最强的预测因素**
- 自闭症 + ID → 癫痫风险显著增加

### 语言发育迟缓
- 特别是**无语言或极低语言功能者**
- 语言发育越迟，癫痫风险越高

### 运动异常
- 肌张力异常、运动协调障碍
- 预示神经系统广泛受累

### 遗传因素
- **特定基因突变**：SCN1A（Dravet 综合征）、SCN2A、CDKL5、MECP2（Rett）、TSC1/TSC2（结节性硬化）
- **拷贝数变异（CNVs）**：15q11-q13 重复（Dup15q）、16p11.2 缺失/重复等
- **遗传综合征**：Angelman、Fragile X、Tuberous Sclerosis
- 遗传性癫痫合并自闭症的比例远高于预期

### 退行性表现（Regression）
- 约 **30% 的自闭症儿童** 经历过语言/社交**退行**
- 其中一部分可能与**未识别的癫痫活动**有关
- 特别是**Landau-Kleffner 综合征**（获得性癫痫性失语）和 **CSWS**（慢波睡眠中持续棘慢波）

## 五、诊断挑战

### 挑战一：症状重叠
- 自闭症的刻板行为、注意力缺失、感觉异常 → 可能被误认为癫痫
- 非典型癫痫发作（如局灶性发作）→ 可能被误认为自闭症行为问题

### 挑战二：沟通障碍
- 自闭症个体难以描述发作前兆或发作体验
- 家长和教师可能**漏诊或误判**

### 挑战三：EEG 解读
- **背景异常在自闭症中常见，但不一定有癫痫**
- 无症状性癫痫样放电（无可见发作）在自闭症中不罕见
- 训练有素的神经生理专家才能准确判读

### 挑战四：研究异质性
- 不同研究定义不同（"癫痫"vs"单次发作"）
- 癫痫诊所 vs 自闭症诊所的诊断标准不同
- 历史诊断框架变化（DSM-IV → DSM-5）

**→ 跨领域沟通不足是最大障碍**

## 六、EEG 检查的指征

### 何时应做 EEG？

- **明确有癫痫发作史**（任何类型）
- **突发行为退行** — 尤其语言或社交技能倒退
- **不明原因的频繁"发呆"事件**
- **夜间异常行为**（夜惊、梦游、夜发性发作）
- **头部外伤或脑炎史后出现的新症状**
- **特定高风险遗传综合征**（如 TSC、Dup15q）

### 何时不需要常规 EEG？

- 无发作史、稳定的自闭症个体
- 单纯行为问题（无发作征象）
- **不建议常规对所有自闭症儿童进行EEG筛查**

## 七、治疗与管理

### 总原则
- **控制癫痫发作是首要目标**
- 但需平衡药物副作用 vs 临床获益
- **治疗的个体化非常重要**

### 药物治疗
- 依据**发作类型**选择抗癫痫药物（AEDs）
- 常用药物：Levetiracetam（Keppra）、Valproic Acid、Lamotrigine、Carbamazepine、Oxcarbazepine等
- **需特别注意药物对行为的影响**：
  - Levetiracetam 可能引起易激惹/攻击（尤其在自闭症中）
  - Valproic Acid 可能加重注意缺陷
  - Lamotrigine 通常对行为影响较小
- 尽量**单药治疗**，避免多药联合

### 非药物干预
- **生酮饮食（Ketogenic Diet）：** 对难治性癫痫有效，尤其在某些遗传综合征
- **VNS（迷走神经刺激器）：** 植入式设备
- **癫痫手术：** 对药物难治性局灶性癫痫
- 行为支持 + 学校安置

## 八、癫痫与自闭症的相互影响

### 癫痫对自闭症的影响
- **认知功能下降：** 频繁发作可导致认知负担，影响学习
- **行为恶化：** 发作增加易激惹、情绪不稳定
- **药物副作用叠加：** AEDs 加重自闭症症状
- **社交隔离：** 担心发作而限制活动

### 自闭症对癫痫的影响
- **治疗依从性差：** 拒绝服药、难以完成EEG
- **发作报告不准确：** 沟通障碍 → 医生难以评估控制效果
- **诊断延迟：** 行为问题掩盖了癫痫

### "治疗沉默"现象
- 很多时候，**控制癫痫后行为也会改善**
- 反之，行为改善可能是癫痫控制良好的信号
- **不应假设行为问题只是"自闭症本身"**

## 九、科学机制：共享神经生物学

### 共同的生物学基础
- 两者都涉及**神经元兴奋/抑制失衡**
- GABA 和 Glutamate 系统在两者中都起关键作用
- 突触可塑性异常

### 共享基因
- 越来越多的基因同时与自闭症和癫痫相关：
  - **离子通道基因：** SCN1A, SCN2A, KCNQ2, CACNA1C
  - **突触基因：** SHANK3, NRXN1, NLGN3
  - **mTOR通路：** TSC1, TSC2, PTEN
  - **转录调控：** MECP2, CHD8, ARID1B

### 发育时机
- 早期脑发育中的电活动异常可影响神经回路形成
- 发育关键期（critical periods）中的癫痫活动可能导致持续性社交/认知缺陷

## 十、家长实用建议

### 1. 注意观察
- **记录"发呆"事件** — 频率、持续时间、伴随症状
- 注意**夜间行为**（夜间发作常见于睡眠中）
- 注意**行为突然变化**（退行、情绪不稳）

### 2. 医疗管理
- 找有癫痫和自闭症经验的**儿童神经科医生**
- **学术医疗中心**通常有最佳的多学科资源
- 用药后密切观察行为变化，及时反馈
- 坚持 EEG 随访和血药浓度监测

### 3. 学校沟通
- 建立**癫痫发作应急预案**（Seizure Action Plan）
- 教师接受基本培训（识别发作、紧急处理）
- 确保学校环境安全

### 4. 安全与生活质量
- 监督洗澡/游泳（防止水中发作）
- 夜间监测（对于频繁发作者）
- 促进正常社交活动，不过度保护
- **癫痫儿童可以有正常的生活**

### 5. 与孩子沟通
- 用简单语言解释癫痫
- 社交故事（Social Stories）帮助理解
- 鼓励孩子表达感受

## 十一、未来方向

1. **精准医学** — 根据遗传病因选择靶向治疗
2. **生物标志物** — 预测哪些自闭症儿童会发展为癫痫
3. **早期干预** — 在癫痫发作前进行神经保护
4. **跨领域合作** — 神经科、精神科、遗传科、行为科协同
5. **ASD-特异性 AEDs** — 开发对行为影响更小的抗癫痫药
6. **发育窗口治疗** — 在关键发育期进行干预以改变疾病轨迹

## 十二、总结

| 层面 | 要点 |
|------|------|
| ✅ **重叠率很高** | 自闭症中癫痫患病率 10–30%，伴 ID 者可达 40% |
| ⚠️ **诊断易被耽误** | 症状重叠 + 沟通障碍 + 跨领域壁垒 |
| 🔍 **退行是一个关键信号** | 语言/社交退行 → 应做 EEG 排除癫痫 |
| 🧬 **共享遗传基础** | 越来越多基因被证实同时关联自闭症和癫痫 |
| 💊 **治疗需平衡** | 控制发作 vs 不加重行为问题—个体化是关键 |
| 👨‍👩‍👧 **家庭是核心** | 观察记录、安全预案、学校协作 |
| 🔮 **精准医学是未来** | 基因型指导治疗选择 |

**核心信息：** 癫痫和自闭症之间的重叠不是巧合——它揭示了两者共享的神经生物学基础。对这种重叠的认识和有效管理，需要**跨领域的合作**和**个体化的诊疗路径**。对于家长来说，最重要的信息是：**行为突然恶化时，不要先入为主地归因于"自闭症本身"——先排除癫痫。**
